Створити Профіль

⚠️ Проксі має відповідати цільовому регіону акаунта (наприклад, US/DE)
💡 Посилання від провайдера для примусової зміни IP-адреси в 1 клік
🌍 Має відповідати геолокації проксі, інакше антифрод-системи побачать невідповідність
🔥 Вставте збережені кукі для обходу Cloudflare / логін перевірок

📖 Інструкція для Адміністратора: Як не спалити акаунти

1. 🌐 Правильний підбір Проксі (80% безпеки)

Використовуйте Residential (Домашні) або 4G/5G мобільні проксі. Ніколи не використовуйте дешеві DataCenter проксі (AWS/DigitalOcean) — Cloudflare і ChatGPT їх миттєво банять.

2. 🛡 Автоматичний захист Fingerprint

Додаток автоматично генерує унікальні апаратні відбитки (Canvas, WebGL, Screen, WebRTC) для кожного профілю. Адміну не потрібно вручну змінювати User-Agent, якщо в цьому немає потреби.

3. 🔒 Захист доступу працівників (RBAC)

Користувачі з роллю Worker не мають кнопок редагування чи створення профілів і не бачать чужих акаунтів. Змінювати доступ можна у файлі users.json.

4. ⚡ Автотестування перед запуском

Перед відкриттям браузера кнопка "🔍 Тест" перевіряє життєздатність проксі та доступність сайту, щоб уникнути витоків IP.

Налаштування Хмарної Синхронізації (Firebase)

Введіть повні ключі безкоштовного проекту Firebase Firestore для авто-синхронізації сесій з колегами.

📥 Бекап профілів

Файл бекапу зашифрований (AES-256-GCM) паролем, який ви вказуєте тут — без нього файл марний, навіть якщо його хтось дістане.

👥 Управління Користувачами та Правами

Призначте, до яких профілів має доступ кожен співробітник. Співробітники бачитимуть та зможуть відкривати лише ті профілі, які ви відмітите прапорцями.
